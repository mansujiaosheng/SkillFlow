# 通用化 Skill Pack

本包由原 Skill Pack 通用化而来，已移除具体项目名称、固定团队划分、业务专属数据流、具体模型字段、专属页面名称，以及原先的层级分类表述。

## 使用原则

- 所有 Skill 均为同级规则，按用户任务意图触发。
- 每个 Skill 都可以独立使用，不依赖 00 号路由才能生效。
- 仓库事实、用户本次目标、安全底线、公开接口和可回滚原则是执行前必须核对的基础。
- 需要具体化时，应先读取当前项目的 README、架构文档、接口定义、配置、测试和 CI 文件。

## 目录说明

- `00-project-skill-router`：按任务类型选择相关 Skill。
- `01-10`：项目上下文、团队流程、Git、环境、接口、AI 协作、风格、测试、日志、分支保护。
- `11-15`：数据处理、规则引擎、机器学习、评分融合、看板可视化等通用能力。
- `16-25`：综合检查、模块边界、命名、任务登记、同步检查、AI 提示词、PR 审核、安全、自动化检查、治理文档。
